# مشارکت در توسعه

راهنمای اصلی مشارکت در [CONTRIBUTING.md](../CONTRIBUTING.md) است. این فایل خلاصه قواعد فنی مخصوص پروژه را نگه می‌دارد.

- Issue یا Pull Request باید مسئله و نتیجه مورد انتظار را روشن توضیح دهد.
- تغییر بزرگ بهتر است پیش از پیاده‌سازی در Issue مطرح شود.
- commitها کوچک، مرتبط و با پیام روشن باشند.
- تغییرات موجود و نامرتبط دیگران بازنویسی نشوند.
- قابلیت جدید باید migration، permission، ترجمه، تست و مستندات لازم را همراه داشته باشد.
- UI در RTL/LTR و اندازه موبایل بررسی شود.
- اطلاعات حساس یا داده واقعی کاربران در نمونه، تست و تصویر قرار نگیرد.

پیش از ارسال Pull Request اجرا کنید:

```powershell
composer ci
npm audit --audit-level=moderate
npm run build
```

در توضیح PR، روش آزمایش دستی، migrationهای تازه و اثر تغییر بر امنیت یا سازگاری نسخه قبل را ذکر کنید.
