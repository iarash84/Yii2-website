# راهنمای ارتقا

ارتقا را ابتدا روی staging یا نسخه‌ای از دیتابیس production آزمایش کنید.

## پیش از شروع

1. نسخه برنامه و تغییرات [CHANGELOG](../CHANGELOG.md) را بخوانید.
2. از دیتابیس، `.env` و فایل‌های upload نسخه پشتیبان بگیرید.
3. Maintenance Mode را فعال کنید.
4. از سالم‌بودن نسخه پشتیبان مطمئن شوید.

## اجرای ارتقا

```powershell
composer install --no-dev --prefer-dist --optimize-autoloader
npm ci
npm run build
php yii migrate --interactive=0
```

سپس Cache و assetهای تولیدشده را از پنل سیستم پاک کنید و صفحات مهم، ورود، فرم‌ها و پنل مدیریت را بررسی کنید.

## بازگشت در صورت خطا

اگر migration جدید `safeDown` قابل‌اعتماد دارد، می‌توان migration مشخص را برگرداند؛ با این حال روش مطمئن برای تغییرات مخرب، بازگرداندن هم‌زمان نسخه کد، دیتابیس و uploadهای هماهنگ است. در میانه خطا migration بعدی را اجرا نکنید و log کامل را برای بررسی نگه دارید.

پس از موفقیت، Maintenance Mode را خاموش و زمان ارتقا را در سوابق نگهداری ثبت کنید.
